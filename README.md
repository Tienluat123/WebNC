# Repository dự án

## Giới thiệu

Ứng dụng hỗ trợ sinh viên lập lịch đi chơi trong ngày cho nhóm bạn, ưu tiên TP.HCM. LLM đọc văn bản, ảnh hoặc nội dung truy cập được từ link để trích xuất địa điểm, hiểu sở thích và đề xuất bản nháp lịch. API cung cấp dữ liệu địa điểm và di chuyển; code tính chi phí, giờ đến/rời và kiểm tra ràng buộc trước khi cập nhật danh sách/bản đồ. Khi thiếu giá hoặc giờ mở cửa, hệ thống yêu cầu bổ sung dữ liệu.

Trong học kỳ, nhóm tập trung vào lập và điều chỉnh lịch; đăng/tìm lịch cộng đồng, bình luận, đánh giá và cập nhật giao thông/thời tiết thời gian thực nằm ngoài phạm vi. PA#4 dự kiến dùng ít nhất 10 ca có đáp án đã kiểm chứng để đo lỗi LLM, khả năng chặn lịch sai và chấp nhận lịch hợp lệ.
